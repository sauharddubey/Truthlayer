# Documentation Directory Structure

This directory contains comprehensive technical specifications, setup instructions, evaluation benchmarks, and architectural documentation for the TruthLayer platform.

## Directory Contents

| File / Subdirectory | Purpose & Description |
| :--- | :--- |
| **`documentation.md`** | Comprehensive single-source technical reference covering system architecture, data models, authentication, security controls, RAG subsystem, API endpoints, and configuration options. |
| **`setup.md`** | Step-by-step developer guide for local installation, environment configuration, database bootstrapping, and containerized deployment. |
| **`PROGRESS.md`** | Chronological technical build log tracking completed features, architectural iterations, and milestone release notes. |
| **`CLAIM_VERIFICATION_EVAL.md`** | Empirical evaluation report analyzing the performance, precision, and recall of claim verification mechanisms against RAG knowledge bases. |
| **`deployment_docs/`** | Production deployment instructions and Software Requirements Specification (SRS) traceability documentation. |

## Documentation Standards

* All documentation within this repository adheres strictly to formal enterprise technical writing standards.
* Emojis are excluded to maintain professional clarity.
* Structural changes to the underlying codebase must be immediately mirrored in these documentation files.
